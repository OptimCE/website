Le code EAN électricité est un numéro de 18 chiffres qui commence par 54. Il ne désigne ni votre compteur, ni votre contrat, ni vous : il désigne le **point d'accès au réseau**, l'endroit où l'électricité entre dans le logement. Depuis le 1er janvier 2022, un arrêté royal oblige les fournisseurs à l'imprimer sur leurs factures, acompte compris.

On vous le demandera tôt ou tard : pour changer de fournisseur, déménager, déclarer des panneaux solaires, rejoindre une communauté d'énergie. Et c'est souvent ce jour-là qu'il manque.

Cet article ne refait pas ce qui est déjà écrit ailleurs sur ce site. [« Lire sa facture d'électricité ligne par ligne »](/guides/comprendre-facture-electricite-ligne-par-ligne/) montre où le code se place sur la facture ; [« Rejoindre une communauté d'énergie en Wallonie »](/guides/rejoindre-communaute-energie-wallonie/) décrit le parcours d'adhésion ; [« Communauté d'énergie : documents et délais CWaPE »](/guides/documents-administratifs-communaute-energie-wallonie/) inventorie les formulaires où les codes sont inscrits ; [« Quel tarif d'électricité choisir en Belgique ? »](/guides/quel-tarif-electricite-choisir-belgique/) compare les formules avant un changement de contrat.

**La question posée ici est plus pratique : que désigne ce code, où le retrouver, combien vous en avez, qui vous le demande, et à qui ne pas le donner ?** L'article décrit la Wallonie et ses cinq gestionnaires de réseau : ORES, RESA, l'AIEG, l'AIESH et le REW ; Bruxelles et la Flandre sont résumées à la fin.

## Ce que désigne un code EAN

« EAN » vient de *European Article Numbering*. Le règlement technique wallon, dans la version adoptée par la CWaPE en août 2026, le définit comme un « champ numérique unique » qui identifie « soit un point d'accès (code EAN-GSRN […]), soit un des acteurs du marché (code EAN-GLN […]) ». Celui de votre facture est le premier.

RESA le résume : « Le numéro EAN n'est ni le numéro de compteur, ni le numéro de client. » Il « reste attaché au lieu de raccordement, quel que soit le fournisseur ou le client ». ORES ajoute qu'il y a « un code EAN par énergie fournie ».

### Code EAN ou numéro de compteur ?

Trois numéros cohabitent sur vos documents :

- **le code EAN**, 18 chiffres, attribué par le gestionnaire de réseau au point d'accès ;
- **le numéro de compteur**, inscrit sur l'appareil. Un compteur remplacé reçoit un nouveau numéro, « alors que le code EAN restera le même » (Sibelga) ;
- **le numéro de client**, attribué par votre fournisseur, qui change avec lui ; l'AIEG précise qu'elle ne le connaît pas.

Le numéro de compteur sert pourtant : c'est lui, avec votre adresse, que les gestionnaires demandent pour retrouver votre code EAN. Photographiez-le une fois pour toutes.

### Pourquoi le code commence par 54

Le code d'un point de fourniture est un *Global Service Relation Number*, une clé du système GS1 qui cite expressément « les points de comptage d'une entreprise d'électricité » parmi ses usages. Un tel code commence par le préfixe de l'organisation qui l'a créé, et les préfixes 540 à 549 relèvent de GS1 Belgium & Luxembourg. La suite varie :

- à Bruxelles, tous les codes commencent par **5414489** (Brugel) ;
- au REW, à Wavre, le code « commence toujours par 5414557 » ;
- à l'AIEG, par **5414**, et « dans de rares cas » par **541449**, à Gesves ;
- l'exemple qu'ORES publie commence par **541449**.

Le début du code ne dit donc pas à coup sûr qui gère votre réseau aujourd'hui. Partez plutôt de votre commune : l'outil [« Quel est mon GRD ? »](/outils/quel-est-mon-grd/) le donne à partir du code postal, pour l'électricité et pour le gaz.

### Ce qui change, ce qui reste

| Ce qui se passe | Le code EAN change ? | Source |
|---|---|---|
| Vous changez de fournisseur | Non | RESA |
| Le gestionnaire remplace votre compteur | Non | AIEG : « le code EAN restera identique » |
| Un nouvel occupant emménage | Non | AIEG : le code est propre « à une adresse et non à un ménage » |
| Votre commune change de gestionnaire de réseau | Pas toujours | Couvin, 2024 : nouveaux codes de l'AIESH, contrat maintenu ; Gesves : l'AIEG gère des codes en 541449 |
| Votre point est resté bloqué dans les systèmes du marché | Oui, chez ORES | Nouveau compteur, nouveau code ; l'ancien « sera détruit » |

*Hypothèses : situations documentées par les gestionnaires wallons au 23 octobre 2026. Nous n'avons trouvé aucune règle générale publiée sur le sort des codes lors d'une reprise de réseau. Le blocage vise des points restés en erreur depuis la mise en service de la plateforme de marché Atrias, en novembre 2021.*

## Où trouver votre code EAN

### Sur vos factures, acompte compris

L'arrêté royal du 9 décembre 2021 impose « le code de changement ou le code d'identification unique du client final pour son point de fourniture » sur la facture de décompte et de clôture (article 3, § 2, 9°), et le même code sur la facture d'acompte (article 5, 11°). C'est la place légale du code EAN, que la CREG définit comme « unique à votre point de fourniture ». Le libellé varie selon le fournisseur ; notre [guide de lecture de la facture](/guides/comprendre-facture-electricite-ligne-par-ligne/) montre où il se trouve.

### Ailleurs que sur la facture

| Où | Ce qu'il faut savoir |
|---|---|
| Espace client du fournisseur | ORES le cite parmi les endroits où retrouver le code |
| myORES | Accès par itsme, eID ou MyGov ; affiche l'EAN ; un code ne peut être lié qu'à un seul compte |
| MyRESA | Réservé aux contrats de fourniture à usage résidentiel ; inscription avec les mêmes coordonnées que sur le contrat |
| Courrier du gestionnaire | Courrier de relève (ORES, RESA), avis de passage, SMS ou e-mail d'invitation à communiquer vos index (RESA), offre de prix pour des travaux (ORES) |
| Document de reprise des énergies | Rempli au déménagement : une case pour l'EAN électricité, une pour l'EAN gaz |
| Le compteur | Parfois une étiquette : le REW en pose « systématiquement » sur les compteurs communicants ; mais la CWaPE écrit que le code « n'est pas affiché sur le compteur » |

*Hypothèses : canaux décrits sur les sites d'ORES, de RESA, de l'AIEG et du REW au 23 octobre 2026 ; l'AIESH n'en décrit aucun. La phrase de la CWaPE vient de son rapport de médiation 2020.*

## Plusieurs codes EAN chez vous

| Ce que vous avez | Combien de codes EAN |
|---|---|
| Électricité et gaz | Deux, un par énergie (ORES) |
| Un compteur exclusif de nuit, chez ORES | Aucun de plus : il « est lié au même EAN que le compteur principal » |
| Un deuxième compteur électrique, par exemple pour une borne | Un de plus : chez ORES, il « disposera de son propre code EAN », et peut avoir son propre fournisseur |
| Des panneaux solaires | Un, parfois deux : la déclaration prévoit un « EAN injection » quand le compteur bidirectionnel a deux codes |
| Un compteur à prépaiement | Le même ; pour recharger, on vous demande ses 13 derniers chiffres (ORES) |

*Hypothèses : la règle de l'exclusif de nuit est celle d'ORES ; nous ne l'avons pas trouvée chez les quatre autres gestionnaires wallons. Le document de reprise des énergies de la CWaPE va dans le même sens : il range l'exclusif de nuit sous l'unique EAN électricité du logement.*

Pour les panneaux, la CWaPE écrivait en 2020 que la plupart des prosumers avaient « un compteur bidirectionnel avec un seul code EAN ». Depuis 2024, une nouvelle installation exige un compteur communicant, et ORES permet de signer avec deux fournisseurs, « un pour l'énergie prélevée et l'autre pour l'énergie vendue ». Vos factures ou votre gestionnaire vous diront si vous avez un code ou deux ; les formulaires de déclaration et de partage demandent les deux quand ils existent.

## Quand on vous demande votre code EAN

### Pour changer de fournisseur

Le nouveau fournisseur fait le travail. La loi du 29 avril 1999 le présume « mandaté » pour mettre fin à l'ancien contrat, avec un préavis de « maximum trois semaines » et sans aucune indemnité (article 18, § 2/3). Il lui faut votre code pour désigner le bon point. Vérifiez qu'il est exact sur la confirmation de contrat : selon le Service de médiation de l'énergie, la cause d'un changement de fournisseur injustifié est « généralement une erreur dans l'enregistrement du (des) code(s) EAN ».

### Pour déménager

Le code est celui du logement ; votre contrat, lui, vous suit. En Wallonie, la fourniture « se poursuit à la nouvelle adresse du client selon les mêmes conditions », sauf exceptions comme une résiliation ou un départ vers une autre région (arrêté du Gouvernement wallon du 30 mars 2006, article 3*bis*).

Le **document de reprise des énergies**, établi par la CWaPE, fixe les relevés au changement d'occupant : codes EAN, index de chaque compteur, deux exemplaires signés par les deux parties. Il « n'équivaut pas à un contrat » : prévenez votre fournisseur « le plus rapidement possible ».

Dans un immeuble, vérifiez le code qu'on vous transmet. La CWaPE constate que les erreurs sont « souvent » des inversions : « un nouvel occupant se voit communiquer le code EAN de son voisin, par exemple par son propriétaire ou un syndic d'immeuble ». Le contrôle fiable reste le numéro de compteur, lu par vous-même.

Si personne ne reprend le point, le gestionnaire de réseau écrit au nouvel occupant dans les cinq jours ouvrables, puis, sans suite, passe dans les quinze jours ouvrables avec un formulaire de régularisation ; à défaut de contrat, il peut suspendre la fourniture (arrêté ministériel du 3 mars 2008).

Deux décisions prises sur un code restent au logement. La participation à un partage, comme l'explique notre [guide du locataire](/guides/guide-solaire-locataire-sans-toit/). Et la **renonciation à la compensation**, exigée pour partager : elle est définitive, et ce droit « ne pourra pas non plus être réactivé dans le chef du nouveau producteur (nouveau propriétaire ou locataire) », précise la CWaPE. Si vous reprenez une maison équipée de panneaux, demandez si l'ancien occupant y a renoncé.

### Pour déclarer une installation

Panneaux, batterie, kit *plug and play* : la déclaration au gestionnaire de réseau passe par le formulaire UP10, dont la version 2.00 du 14 novembre 2025 demande l'« EAN prélèvement » et, s'il existe, l'« EAN injection ». Selon la procédure de l'AIEG, le demandeur est le client final « rattaché au code EAN concerné », et le formulaire doit arriver dans les 45 jours calendrier suivant le contrôle RGIE. Pour une batterie, cette déclaration a une conséquence que détaille [« Batterie domestique : le prix et l'alternative »](/guides/batterie-domestique-prix-ou-partage-energie/).

### Pour rejoindre une communauté d'énergie

Votre code EAN est la pièce d'identité de votre participation :

- **le gestionnaire de la communauté l'inscrit** dans l'annexe 6 du formulaire de partage de la CWaPE, avec votre numéro de compteur, votre gestionnaire de réseau, votre adresse et votre statut, résidentiel ou non. Chaque installation de production y figure par son EAN d'injection, dont le producteur doit être titulaire ;
- **vous signez** la déclaration sur l'honneur (annexe 8) comme « titulaire du point d'accès », c'est-à-dire signataire du contrat avec le fournisseur, et vous y reportez votre code de prélèvement et, le cas échéant, d'injection ;
- **le gestionnaire de réseau vérifie**, code par code, que la fonction communicante du compteur est activée et que la compensation a été abandonnée.

Une règle en découle : « un point d'accès ne peut participer qu'à une seule activité de partage d'énergie » (décret électricité wallon, article 35*quaterdecies*, § 1er, 4°). Pas de cumul, donc, entre un partage dans votre immeuble et une communauté d'énergie : le gestionnaire de réseau le contrôle.

Pour une communauté d'énergie renouvelable, le périmètre se vérifie aussi par code : aucune base publique ne relie les codes EAN aux postes de transformation, mais le gestionnaire peut délivrer une attestation. Et les participants n'ont pas besoin du même gestionnaire : la demande s'introduit auprès « du ou des gestionnaires de réseaux » concernés. Dans OptimCE, chaque compteur d'une communauté est d'ailleurs enregistré avec son EAN, son numéro et son gestionnaire ([Démarrer une communauté sur OptimCE](/fonctionnalites/premiers-pas/)).

### Pour deux usages moins connus

Le **GreenCheck** de la CWaPE affiche, à partir de votre code électricité, « le pourcentage d'électricité verte que vous consommez par mois », pour les contrats wallons ; notre analyse de l'[électricité verte](/guides/electricite-verte-belgique-vraiment-verte/) dit ce que ce chiffre prouve. Et le nouveau règlement technique, qui doit encore être publié au Moniteur belge, vous donne accès gratuitement à vos données de prélèvement et d'injection « moyennant communication de [votre] code EAN ».

## Je ne trouve pas mon code EAN

Le gestionnaire de réseau le retrouve : c'est lui qui l'attribue. L'outil [« Quel est mon GRD ? »](/outils/quel-est-mon-grd/) vous dit lequel contacter ; pour le gaz, en Wallonie, ce sera ORES ou RESA, les deux seuls à le distribuer.

Préparez votre **adresse exacte**, numéro de boîte compris, et votre **numéro de compteur**, lu sur l'appareil. L'AIEG et le REW n'envoient le code qu'« en cas de bonne correspondance » entre les deux. Le nouveau règlement technique adopté par la CWaPE prévoit une réponse dans les dix jours au plus, sur la base de ces deux informations.

| Gestionnaire | Comment demander | Comment le code arrive |
|---|---|---|
| ORES | Formulaire « Connaître mon code EAN » sur demandes.ores.be : adresse, puis quatre derniers chiffres du numéro de compteur ; chat de 8 h à 20 h en semaine ; 078/15.78.01 | Par SMS, au numéro de GSM qu'ORES ou votre fournisseur connaît ; sinon un conseiller cherche : 48 heures par SMS, ou trois jours ouvrables par courrier |
| RESA | Service clientèle au 04/220 12 11, du lundi au vendredi de 8 h à 18 h, formulaire de contact ou chat ; MyRESA | Délai non publié |
| AIEG | Formulaire « Demande de code EAN » (adresse, numéro de compteur, signature) à renvoyer par le site ; 085/27.49.00 | Par e-mail, si adresse et numéro de compteur concordent |
| AIESH | Aucune procédure publiée : 060/45.91.60 ou clients@aiesh.be | Non précisé |
| REW | Formulaire « Demande de code EAN » sur rew.be ; 010/22.26.53 | Par courriel, si adresse et numéro de compteur concordent |

*Hypothèses : procédures publiées par les gestionnaires, consultées le 23 octobre 2026. Le formulaire d'ORES envoie tous les codes de l'adresse, électricité et gaz, et limite le nombre de demandes.*

Le formulaire d'ORES prévient d'emblée : « Toute tentative abusive d'obtention du code EAN (ex : dans le cadre de démarchage commercial) pourra faire l'objet de poursuites judiciaires. » Pour un simple appel, en revanche, le code n'est pas nécessaire.

## Faut-il garder son code EAN pour soi ?

Oui, sans en faire un secret. ORES le qualifie de « donnée confidentielle qui n'est communiquée qu'à l'occupant ou au propriétaire du bâtiment », car « une personne mal intentionnée pourrait changer votre contrat d'énergie ».

Le risque documenté est d'abord administratif. Le Service de médiation de l'énergie a reçu **852 signalements de reprises injustifiées en 2023**, contre 1 042 en 2022 et 182 en 2021. À l'origine, le plus souvent, un fournisseur qui associe le nom d'un nouveau client à un code EAN lié à l'adresse d'un autre. Son rapport 2025 compte par ailleurs **359 « mystery switches »**, contre 386 en 2024 ; les deux séries viennent de publications différentes et ne se comparent pas. La fraude existe aussi : un cas publié montre un démarcheur qui avait utilisé les codes EAN d'une autre cliente.

Trois protections jouent pour vous :

- depuis le 1er janvier 2024, un vendeur à domicile ne peut laisser qu'« une offre sans engagement et non un contrat de fourniture d'énergie », à confirmer « après une période de minimum trois jours » (arrêté royal du 12 novembre 2023) ;
- tout contrat d'énergie se rétracte gratuitement dans les 14 jours calendrier, « quelle que soit la manière dont vous avez conclu le contrat » (SPF Économie) ;
- c'est au fournisseur qui vous a repris à tort d'annuler la reprise.

Une règle a changé en votre défaveur : avec le protocole de marché MIG6, le fournisseur dont le client a été détourné peut facturer la consommation de la période. Le Service de médiation demande de revenir à l'ancienne règle, où aucun des deux ne le pouvait.

**Donnez votre code** au fournisseur choisi, au gestionnaire de la communauté que vous rejoignez, à votre installateur, à la personne qui reprend votre logement. **Pas** à un démarcheur, tant que vous n'avez rien décidé. Le signal habituel d'une reprise non demandée, selon le Service de médiation : une carte de relevé du gestionnaire de réseau, puis une lettre de fournisseur, sans démarche de votre part. Écrivez au fournisseur concerné et gardez une copie, puis, faute de solution, saisissez le Service de médiation de l'énergie, compétent pour les contrats et le démarchage ; le service régional de la CWaPE traite les index et les compteurs.

## Bruxelles et la Flandre

**À Bruxelles**, tous les codes commencent par 5414489. Sibelga les retrouve en ligne à partir de l'adresse et du numéro de compteur, ou au 02 549 41 00.

**En Flandre**, Fluvius indique un code qui « begint altijd met het cijfer 54 », imprimé sur la facture, un devis de Fluvius ou l'autocollant du compteur, et répond à son formulaire dans les cinq jours ouvrables ; le code d'un tiers exige une procuration. Pour partager l'énergie, chaque participant est enregistré par son code dans Mijn Fluvius, et chaque point d'accès ne peut entrer que dans une seule communauté d'énergie.

## Ce qu'il faut retenir

1. **Le code EAN désigne le point d'accès**, pas le compteur, ni le contrat, ni vous : il survit au changement de fournisseur, de compteur et d'occupant.
2. **Dix-huit chiffres, toujours 54 au début** ; la suite ne suffit pas à identifier votre gestionnaire actuel.
3. **Il figure sur vos factures depuis 2022, acompte compris**, et dans myORES, MyRESA ou le courrier de relève.
4. **Un code par énergie, parfois plus** : un deuxième compteur ou une injection séparée ont le leur.
5. **Un point d'accès, une seule activité de partage** : votre code vous inscrit dans une communauté d'énergie.
6. **Perdu ? Le gestionnaire de réseau le retrouve** avec votre adresse et votre numéro de compteur.
7. **Réservez-le aux démarches choisies** : les reprises injustifiées naissent surtout d'erreurs de code.

## FAQ

### Où trouver mon code EAN d'électricité ?

Sur n'importe quelle facture récente, acompte compris : la loi l'impose depuis 2022. Sinon dans l'espace client du fournisseur, myORES ou MyRESA, sur le courrier de relève ou le document de reprise. En dernier recours, le gestionnaire de réseau le retrouve avec votre adresse exacte et votre numéro de compteur.

### Le code EAN change-t-il quand on déménage ou qu'on change de compteur ?

Non : il appartient au logement, et un compteur remplacé garde le même code. Exceptions documentées : la reprise du réseau de Couvin par l'AIESH en 2024 et les points bloqués chez ORES. En immeuble, vérifiez le code reçu : c'est souvent celui du voisin, selon la CWaPE.

### Le gaz a-t-il un code EAN différent de l'électricité ?

Oui, un code par énergie, tous deux de 18 chiffres commençant par 54. La CWaPE met en garde contre la confusion : vérifiez lequel vous transmettez, surtout pour une démarche qui ne vise que l'électricité.

### Pourquoi mon code EAN commence-t-il par 54 ?

Parce que c'est un identifiant GS1, et que les préfixes 540 à 549 relèvent de GS1 Belgium & Luxembourg. La suite dépend de l'organisme qui a créé le code (5414489 à Bruxelles, 5414557 au REW, 5414 à l'AIEG), pas forcément de votre gestionnaire actuel.

### Peut-on changer mon fournisseur avec mon seul code EAN ?

Le risque existe, selon ORES, mais les reprises injustifiées viennent surtout d'erreurs de code : 852 signalements en 2023. Depuis 2024, aucun contrat ne se signe à la porte, et tout contrat se rétracte en 14 jours. En cas de reprise non demandée, écrivez au fournisseur, puis au Service de médiation de l'énergie.

### Faut-il son code EAN pour rejoindre une communauté d'énergie en Wallonie ?

Oui : il vous identifie dans l'annexe 6 du formulaire de partage et dans la déclaration que vous signez comme titulaire du point d'accès. Un même point d'accès ne peut participer qu'à une seule activité de partage.
