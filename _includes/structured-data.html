{%- comment -%} Emits ONE @graph per page holding every entity we own, each with an @id so the nodes reference each other instead of repeating anonymous copies. jekyll-seo-tag also emits a JSON-LD block and its script tag cannot be suppressed. What it CAN do is take a type override, so _config.yml sets `seo: { type: WebPage }` on posts and on index.html. That demotes its node from BlogPosting/WebSite to a page-level WebPage, so it no longer describes the same entity class as the Article/WebSite nodes below. Its drop keys are a fixed list with no @id and no inLanguage, which is why the graph lives here and not there.
